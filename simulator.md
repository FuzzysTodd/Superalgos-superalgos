# Nexus Treasury Simulator UI

- One-click URL: http://127.0.0.1:5001
- Start: `python simulator/app.py` or `scripts/Run-Simulator.ps1`
- Dashboard: Vault pie chart, pending tx list, sign/execute buttons, audit log
- Provenance: `.agent/provenance/*.json` records agent decisions and CI outcomes
- Self-healing: Agent retried attempts with diagnostics, rollback, and test isolation
